# 🛒 TechNova E-Commerce Project

> 💻 A modern electronics e-commerce storefront built as a **Diploma Student Project** using HTML, CSS & JavaScript.

---

## 📌 Overview

**TechNova** is a modern and responsive static e-commerce website designed for an electronics shop. 🖥️📱

The project provides a complete front-end shopping experience including:

* 🛍️ Product browsing
* 🔎 Product search
* 🏷️ Category filtering
* 💰 Price filtering
* 📊 Product sorting
* 🛒 Shopping cart interactions
* 📱 Responsive navigation
* 🌙 Dark/Light theme

---

## ✨ Key Features

### 📱 Responsive Design

* 💻 Desktop friendly
* 📱 Mobile friendly
* 📲 Responsive navigation
* 🎨 Modern UI design

### 🎯 Product Features

* 🛍️ Product listing
* 🔎 Search with autocomplete
* 🏷️ Category filters
* 💰 Price range slider
* ⭐ Product rating
* 📊 Sort by popularity, price & rating

### 🛒 Shopping Experience

* 🛒 Shopping cart
* 💳 Checkout page
* 📦 Product details page
* 🔐 Login page
* 📝 Registration page

### 🎨 UI Features

* 🌙 Dark/Light mode
* 💾 Theme preference saved with Local Storage
* 📱 Mobile navigation menu
* 🎞️ Hero slider
* ✨ Interactive UI elements

### 1️⃣ Clone or Download

Download the project and open the project folder in your code editor.

## 📸 Main Sections

### 🏠 Homepage

Features a hero slider, promotional content and featured products.

### 🛍️ Shop Page

Users can browse products, filter by category and price, and sort products.

### 📦 Product Details

Displays individual product information.

### 🛒 Shopping Cart

Allows users to view selected products before checkout.

### 💳 Checkout

Provides a front-end checkout form.

### 🌙 Theme System

Users can switch between **Dark Mode** and **Light Mode**, with the preference stored using Local Storage.

---

## ⚙️ JavaScript Data Layer

Product information is managed through:

```text
js/products.js
```

This provides a reusable product data structure for the website. 📦

---

## 📝 Notes

> ⚠️ **This is a static front-end project.**

* 🚫 No back-end server is included.
* ⚡ Cart and checkout interactions are handled using front-end JavaScript.
* 📦 Product data is stored in `js/products.js`.
* 💳 No real payment processing is implemented.
* 🔐 Login and registration are front-end demo pages.
